Codec is a music player that connects to a user-selected Codec server. It supports streaming, offline downloads, playlists, artwork, a live visualizer, playback transfer, and shared queue sessions. Music and hosted accounts are not sold in the app.

A review server is provided so you do not need to install a server or another app:
Server URL: https://codec-review.codie.sh
Auth token: [REVIEW-ONLY TOKEN]

The connection screen uses a server URL and an auth token; there is no username. No account registration, purchase, or two-factor code is needed to access this review server. The server contains 100 licensed demonstration tracks. This demonstration collection is not included with a normal app download.

To test:
1. Enter the server URL and auth token on the connection screen and tap Connect.
2. Open Library, choose a playlist, and play a song. Tap the mini player to open Now Playing, playback controls, and the queue.
3. Open Visualizer while music is playing on this device. Use its expand control to open it full screen.
4. Download a song and wait for it to finish. Open Library > Downloaded. Disconnect Wi-Fi and cellular data, then play a downloaded song to test offline playback. Reconnect afterwards.
5. Open the palette picker from Home to change the interface colors.
6. Optional: open the same server URL in a browser and connect with the same token. Use the playback-device controls to transfer playback between the app and web player. Pass the Aux lets invited guests add songs to a shared queue.

Only user-provided music is available outside the review server. The app does not provide a commercial streaming catalog.
